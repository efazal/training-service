Training Service is installed in namespace {{ .Release.Namespace }}.

{{- if .Values.route.enabled }}

Get the API URL:
  oc -n {{ .Release.Namespace }} get route {{ include "training-service.fullname" . }} -o jsonpath='https://{.spec.host}{"\n"}'

Open /docs on that URL for the API reference. API calls use an OpenShift bearer token.
{{- else }}

Access the API locally:
  oc -n {{ .Release.Namespace }} port-forward service/{{ include "training-service.fullname" . }} 8080:{{ .Values.service.port }}

Open http://localhost:8080/docs for the API reference.
{{- end }}

The runtime catalog is discovered automatically. Ray/Kueue and training inputs
must already be available on the cluster before submitting a training job.
